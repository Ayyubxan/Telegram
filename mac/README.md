# Nexo — Mac clipboard companion of the Telegram fork

Menu-bar app (SwiftPM, macOS 13+). Pairs with the fork's "Mac clipboard" settings (Settings → Mac clipboard):
copied text / images / files travel both ways over Wi-Fi (Bonjour `_nexo._tcp`), Bluetooth LE, or the ntfy relay.
Clipboard only — no habits, no finance.

    ./build.sh            # build/Nexo.app
    ./build.sh --install  # replace /Applications/Nexo.app and launch
